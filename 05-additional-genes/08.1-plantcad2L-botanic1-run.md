# PlantCAD2-large and Botanic1 predictions for the TPS genes

Added tps genes scores with PlantCAD2-large, Botanic1-small/-large on 2026-11-04 (batch 2, produced 2026-10-29).
`10-multi-plot_tx.R` and `06-model-comparison/02-merge-MSIC-with-marks.R` read these results by folder name.

- Models / output folders:
  - PlantCAD2-large → `out/{a_thaliana,z_stapffii}_tps_PCAD2L_results/`
  - Botanic1-small → `out/{a_thaliana,z_stapffii}_tps_Botanic1S_results/`
  - Botanic1-large → `out/{a_thaliana,z_stapffii}_tps_Botanic1L_results/`
- Window: 4096 bp, centred on each masked base. Context comes from the genome.
- Scored FASTAs are identical to `out/tx_a_thaliana.fa` and `out/tx_z_stapfii.fa`.
- The `chrom` column of `msic.csv` was renamed to `header`, to match the top 15 results.
