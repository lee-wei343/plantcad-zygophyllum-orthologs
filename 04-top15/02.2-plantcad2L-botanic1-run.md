# Per-base masked-LM predictions and MSIC: A. thaliana and Z. stapffii genes

Predictions from two DNA language models at every base of 15 _Arabidopsis thaliana_
and 15 _Zygophyllum stapffii_ gene windows.

- **PlantCAD2-L:** `kuleshov-group/PlantCAD2-Large-l48-d1536`
- **Botanic1-S:** `living-models/Botanic1-S`

Produced 2026-10-13/14 with `workflow/rules/tx_msic.smk` in the `scripting` repo.

Flanksize: 4 kb

## Layout

```
tx_a_thaliana/
  tx_a_thaliana.fa            given gene windows (the scored sequences)
  tx_a_thaliana.ctx2048.fa    same windows + 2048 bp genomic context per side
  PlantCAD2-Large-l48-d1536/
    msic.csv                  per-base predictions + MSIC, all 15 genes
    msic_profiles.png         MSIC profile, one panel per gene
  Botanic1-S/                 (same two files)
tx_z_stapffii/                (same layout)
```

## How the predictions were made

- **Window:** each base of each given record is masked and predicted from a 4096 bp
  window centred on it: 2048 bp to the left and 2047 bp to the right.
- **Context source:** the context comes from the genome, not from padding, so the
  first and last bases of each record also have full context.
  - A. thaliana: TAIR10.1 (NCBI GCF_000001735.4).
  - Z. stapffii: the genome assembly provided as a Google Drive file.
  - Every record was checked base for base against its genome slice, and no
    flank was clipped at a contig end.
- **Scored positions:** every base of the given records (`tx_*/tx_*.fa`) is
  scored. The extra 2048 bp in `tx_*/tx_*.ctx2048.fa` is context only and never scored.
- **Records:** gene-sense, i.e. reverse-complemented for genes on the − strand.
  Each record already includes 1000 bp of flank around the transcript, as given by
  `flank:1000` in its id. The coordinates in the id are 1-based inclusive on the
  forward strand.

## `msic.csv` columns

Comma-separated with a header row; one row per base, records concatenated in FASTA order.

| column                        | meaning                                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `chrom`                       | full record id from the FASTA header, e.g. `AT1G11870.1\|chrom:1\|+\|4002846-4007738\|n_exons:10\|flank:1000` |
| `position`                    | 0-based index into the given record (gene-sense, 5'→3'), contiguous `0..L-1`                                  |
| `ref`                         | reference base (lowercase `a/c/g/t`)                                                                          |
| `p_a`, `p_c`, `p_g`, `p_t`    | model probability of each base at the masked position (sum to 1)                                              |
| `p_ref`                       | probability of the reference base                                                                             |
| `argmax_base`, `argmax_match` | most probable base; 1 if it equals `ref`                                                                      |
| `p_max`                       | max(`p_a`..`p_t`)                                                                                             |
| `ic`                          | information content in log4 units: 1 − H(p)/log 4, range 0..1                                                 |
| `msic`                        | (1 − 2·(`p_max` − `p_ref`)/`p_max`) · `ic`, range −1..1                                                       |

Interpretation of `msic`:

- It equals `ic` when the reference base is the model's top prediction.
- It goes negative when the model confidently predicts another base.
- The plots colour it green above +0.5, red below −0.5 and grey in between. The black
  line is a 100 bp centred rolling mean; dotted lines mark transcript start and end.

Read with e.g. Python `pandas.read_csv(...)` or R `read.csv(...)`.
